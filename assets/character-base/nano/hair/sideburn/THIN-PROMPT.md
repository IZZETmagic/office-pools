=== THE ONE AND ONLY CHANGE: MAKE THE SIDEBURNS MUCH THINNER ===

The SECOND reference image is the haircut you must reproduce. Copy it EXACTLY: the same very
short cut, the same hairline across the forehead, the same outline over the skull and temples,
the same slightly darker swoosh texture on top, the same two browns. It must read as the
identical haircut on the identical head.

Change ONE thing and nothing else.

⚠ EACH SIDEBURN IS MUCH THINNER. In the second reference image, the strip of hair in front of
each ear is a thick block. Make it about ONE THIRD AS WIDE as it is there — a slim, narrow
sliver of hair hugging the very edge of the face just in front of the ear.

It keeps the SAME LENGTH as in the reference — it still ends at about the middle of the ear.
Only its WIDTH changes.

It narrows smoothly and steadily on the way down, ending in a fine soft taper. Its edges are
clean and smooth. There is NO notch, NO step, NO spur and no piece bitten out of it anywhere
along its length — the reference has a small notch cut into the bottom of each sideburn and
that must be gone.

If you are unsure how thin to make them, make them THINNER rather than thicker. Too thin is
fine. Leaving them thick is the mistake.

BOTH SIDEBURNS ARE IDENTICAL — same width, same length, ending at exactly the same height on
the left and the right.
